# Execute Command

将用户消息中 `$execute` 之后的内容视为本次任务输入。

1. 每次响应以 `[MODE: EXECUTE]` 开头。
2. 先读取并遵循 `riper-core` 与 `execute-mode` skills。
3. 根据任务输入定位并读取对应任务文件中的已批准编号实施清单。未能唯一确定任务文件时，先询问用户。
4. 严格按清单顺序逐项实施，不得增加计划外改动、跳过步骤或擅自优化。
5. 使用补丁或编辑工具修改文件；不得使用命令行、脚本或批量替换来写入源码。
6. 每个阶段完成后，按 RIPER-5 追加修订规则更新任务文件的当前执行步骤与任务进度，并请求用户确认阶段结果。
7. 遵守仓库 `AGENTS.md` 的验证限制，不得替用户运行构建、类型检查、lint、测试或应用启动命令。
8. 发现必须偏离计划的问题时立即停止实施，记录偏差并请求用户明确批准返回 PLAN 模式。
