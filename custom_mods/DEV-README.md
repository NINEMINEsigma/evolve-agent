# custom_mods — 系统功能指导

本目录保存按需读取的mod正文；运行时接入已在源码实现，实际运行验收仍待用户执行。本文覆盖此前未接入草案，不沿用YAML frontmatter、禁止关联环或仅展示关联建议的旧设计。规范术语见根DEV-glossary。

## 布局与配置

每个直接子目录代表一个规范名称，包含纯Markdown `MOD.md` 和同级 `MOD.md.meta`。名称使用ASCII字母开头、字母/数字/下划线/连字符，最长64字符；精确区分大小写，同时拒绝跨平台大小写等价冲突。不递归发现分类目录，不接受路径或URL作为名称。

元数据复用项目现有独立 `[key]` 分块文本，不执行YAML或表达式。只支持：

| 键 | 含义 |
|---|---|
| description | 必填的非空单行简介，最多256码点 |
| related | 可选，每行一个精确名称；程序机械递归读取，允许自关联和环，调用内去重 |
| keywords | 可选，每行一个字面关键词；区分大小写子串匹配，任一命中，无正则/分词/语义判断 |

空行忽略，值去首尾空白；未知/重复键、关联缺失、坏名称或空正文失败。没有meta的文档不从正文猜简介。独立的方括号行会被解析为新键，不能不经说明将这种行当普通关键词值。正文交叉引用不自动构成related。关联配置应避免把可选替代功能全部连成必读闭包。

根不存在表示无可选安装；已有目录/文件不可读、类型错误、链接或Windows reparse point、坏编码不伪装成空目录。根通过项目根定位，不随工具cwd变化，不复制进运行源码副本，不提供custom_mods:沙盒前缀。只读取受信任本地文档，不执行脚本、安装或网络请求。

## 发现与主动读取

普通主会话、随意聊聊、多Agent参与者和普通子Agent默认获得名称/简介目录，正文不常驻。临时Agent继续没有system prompt，通过工具查询目录。

`RecallMod`位于core、safe、EVERY，受现有Loop权限过滤；省略names列目录，提供非空names数组一次读取多个目标及全部递归关联。支持跨调用显式重读，每次读取当前全文，不因以前加载过而返回空结果。输入目标与关联按稳定先序遍历、同次去重，允许环，不作拓扑排序。

正文随正常配对工具结果进入本会话上下文，正文与来源在正式ModTextBlock中只保存一份。加载不调用LoadToolset，不扩大沙盒/工具/审批授权，也不自动执行介绍的功能。

## 自动关键词固着器

所有Agent Loop在实际模型请求前处理尚未评估的正式顶层Role.USER消息；包括人类、父Agent和系统投递。原始消息先保存，关键词处理不发生在接收或关闭刷新中。只匹配原正文文字段，不扫描媒体载荷/URL、转发缓存或已有suffix，不跨两个文字块拼出关键词。

工具结果内嵌的用户补充不触发；被转换成正式顶层user的follow-up会触发。辅助标题、摘要、审批模型不属于此机制的Agent Loop。

命中后机械读取关联闭包，内容成为类型化mod固着器。自动去重只检查当前正式消息的块类型、名称、资源所属主会话和角色可见性，不比较MOD全文、不通过摘要中的名称推断全文还在、不保存永久loaded_mods名单。

正文删除/压缩后加载依据随之消失，下条新匹配消息可以补载。文件更新不自动重载已有同名全文；显式工具读取仍取最新值。资源所属主会话改变后，旧归属块不阻止新会话补载。多Agent共享History不代表每个角色都能看到某块。

processed字段仅表示某条user输入已评估，不是mod加载状态。编辑/重新生成可重置目标输入，原固着器与其他hooks独立保存。关闭只落原始输入和未处理状态，后续显式恢复生成才处理；临时Agent只在内存中处理，不新增磁盘历史。

## 模板

正文允许简单 `{{key}}` 或带内侧空白形式，单次替换；前置反斜杠表示保留字面模板，不二次展开替换值。显式值包括资源主会话ID（session_id/resource_session_id）、资源归属介绍、Gateway端口、MCP逻辑配置路径、文件/下载/字体URL前缀与变量目录名。

未知语法、缺值失败，不置空、不执行表达式、不读取任意环境变量/属性/密钥。人格选择和fallback真实指派由其已有常驻事实提供，通用文档不捏造不可用路径。历史中的渲染结果是读取时快照，不承诺随配置实时变化。

## 预算与失败

常量统一在entity/constant/mods.py：256项目录、64个原始显式目标、每项256关联/32关键词、单关键词128码点、单meta 8KiB/元数据总2MiB、单正文64KiB/所选正文总512KiB。自有完整编码内容上限1MiB，包括正文、来源头部和包装；不包含既有工具_meta或用户嵌入媒体，不是所有工具最终传输消息的通用限额。

有界读取、同操作同名正文只读一次，变化或超预算整批失败，不截断全文冒充成功；没有跨文件原子快照、常驻缓存、watcher或自动重试。

主动工具失败沿原工具结果边界；自动准备/目录发现失败沿原Loop/队列边界传播，主会话队列可能请求全应用FAILURE关闭。没有新增恢复器、静默跳过或空文档降级。原输入先保存，候选成功保存后才发布；保存失败仍由既有必要History错误责任承接。

## 存储与展示

正式History使用easysave v2，v1只在明确兼容路径读取，新程序优先v2且坏v2不回退。旧文件写v2会保留冻结v1项，不是允许旧运行包继续使用的降级方案；须完整部署相关运行包。

Provider正文保留原工具内容和附加文本；UI独立清理内部字段，通过已有专门字段展示耗时及嵌入消息。主聊天复用suffix/history_updated；子会话固着器在真实上下文、持久History及现有快照/回放中保留，本次不增加实时子会话后缀同步协议。

开发助手AI仅实施源码和文档，未启动应用、校验、构建或运行验收。安装目录中的具体文档、关键词与专属行为不在本通用开发文档中维护清单。
