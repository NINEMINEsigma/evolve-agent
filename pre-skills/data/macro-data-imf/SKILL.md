# IMF 宏观经济数据（通用版）

> 对应能力：IMF 世界经济展望（WEO）数据库——190+ 国家/地区的 GDP 增长、通胀、政府债务、失业率、贸易差额等宏观指标的历史统计与预测；以及 COFER 外汇储备货币构成数据。

## 何时使用

- 跨国宏观指标对比、单国宏观时序、官方预测值（"IMF 预测某国明年 GDP 增长 X%"）。
- 储备货币份额类问题（美元/欧元/人民币等占比）→ COFER。
- 宏观数据优先用 IMF/世界银行这类官方源，不用通用搜索或记忆。

## 数据源通用调用模式

1. **Describe**：取数据源描述文档（指标代码、国家/地区代码、期间与频率约束、各 API 参数）。
2. **选 API**、**构造参数**：注意指标口径（实际值/预测值）、国家代码、年份区间。
3. **Call**：失败如实报告；成功先存文件再作答。

## 实务要点

- 区分**历史值与预测值**：WEO 同时含两者，回答时说明哪些是估计/预测及对应发布期（春季/秋季展望）。
- 跨国对比注意指标口径一致（如"一般政府总债务" vs "中央政府债务"）。
- 常用指标：实际 GDP 增长、CPI 通胀、失业率、财政余额/GDP、政府债务/GDP、经常账户/GDP。

## 引用规范（强制）

凡来自专业数据源的数字或事实，紧跟引用：`[来源: IMF — 数据集/接口, 截至日期]`。元数据只用工具实际返回的信息；绝不伪造数据或引用。
