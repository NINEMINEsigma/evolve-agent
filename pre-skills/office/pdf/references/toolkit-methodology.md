# PDF：生成与处理（通用版）

> 对应能力：用 HTML + 分页引擎生成专业 PDF（学术论文、报告、文档）；用 Python 处理现有 PDF（读取、提取、合并、拆分、填表）；支持 KaTeX 数学公式、Mermaid 图、三线表、引用；用户明确要求时也支持 LaTeX 编译。

## 路由选择

| 路线 | 触发条件 |
|------|---------|
| **HTML（默认）** | 一切 PDF 生成请求（"做个 PDF/报告/论文"） |
| **LaTeX** | 用户明确要求 LaTeX、.tex 或指定编译器 |
| **处理现有 PDF** | 提取文字/表格、合并拆分、填表单、改元数据 |

**默认走 HTML**。只有用户点名才走 LaTeX。

**Markdown 优先交接**：当上游工作流（如深度研究）交付了完整 Markdown 报告，把它当作权威内容源，经 HTML 路线转成 PDF——HTML 只是呈现层投影：保留报告的章节、表格、图、论断和来源 ID。引用标记（如 `[^123^]`）必须映射到真实来源；未解析的标记要保留并警告缺失，绝不伪造或静默删除来源。

## 封面风格（HTML 路线）

| 场景 | 风格 |
|------|------|
| 学术论文、毕业论文、正式课程作业 | **极简**（白底、居中、无装饰） |
| 报告、提案、专业文档 | **设计款**（从风格库选：莫兰迪曲线/水墨/瑞士网格/几何色块/渐变丝带/正式双线框等） |
| 拿不准 | 默认**设计款**——纯文字封面 = 平庸 |

## 引用格式

| 文档语言 | 格式 |
|---------|------|
| 中文 | GB/T 7714（用 [J][M][D] 标识） |
| 英文 | APA |
| 混排 | 中文文献 GB/T 7714，英文文献 APA |

## 核心约束

1. **语言一致**：输出语言与用户提问语言一致；用户显式指定时遵从用户。
2. **体量达标**：指定字数 ±20%；指定页数严格相等（末页可不满）；范围必须落入区间；"不少于 X"最多到 2X。禁止任意缩水、禁止用大量列表注水凑页。简历默认 1 页、紧凑边距（1.5cm）。
3. **大纲必遵**：用户给了大纲就严格遵循（章节标题可微调措辞，层级和顺序不动）；大纲有问题先问用户再改。无大纲时按文档类型用标准结构：学术论文 IMRaD；商业报告结论先行（执行摘要→详细分析→建议）；技术文档 概述→原理→用法→示例→FAQ。
4. **先搜后写**：涉及统计数据、政策法规、学术研究、时事，或任何你不百分百确定的内容，必须先搜索。搜索多次失败就告诉用户，不要编数据。引用必须真实——作者、标题、年份、期刊均可查证。
5. **交叉引用可点击**：图表/公式/章节引用用锚点链接实现（`id` 放在容器顶部）。

## 技术栈速查

| 路线 | 工具 |
|------|------|
| HTML | 无头浏览器（Playwright/Chromium）+ Paged.js 分页；KaTeX 公式、Mermaid 图 |
| 处理 | pikepdf（表单/页面/元数据）、pdfplumber（文字与表格提取）、LibreOffice（Office→PDF） |
| LaTeX | Tectonic |

## 验证

- 转换后必须验证 PDF 可打开、页数符合、公式图表渲染正常；版式敏感任务渲染成图片抽查。
- 把转换警告/错误当作可操作的反馈，在副本上修复重试，直到通过。绝不压制失败。
