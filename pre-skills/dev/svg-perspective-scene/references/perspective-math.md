|---|---|---|

| 右上 | (1280,0) | (928, 182) |
| 左下 | (0,720) | (352, 505) |

四条墙棱 = 画布角点 → 对应后墙角点，全部指向 VP。

### 踢脚线 / 檐口线 / 护墙板

- 踢脚线：沿墙脚线向内偏移一点，同样过 VP：`M 0,704 L 352,494 M 1280,704 L 928,494 M 352,494 L 928,494`
- 檐口线同理（顶部）：`M 0,16 L 352,194 ...`
- 后墙上的水平分割线（护墙板）：纯水平线，如 `M 352,430 L 928,430`

### 地板缝

- 纵向板缝：底边取点 (x, 720)，与 VP 连线，止于后墙脚线 y=505。交点参数 t=(720−505)/(720−330)=0.551，交点 x' = x + 0.551×(640−x)
- 横向板缝：水平线。y=570 处左右端点由两侧墙脚线插值：t=(720−570)/215=0.698，x=0+0.698×352=245.6 与 x=1280−245.6

## 2. 通用收束公式

任意点 P 向 VP 收束比例 s：

```
P' = P + s × (VP − P)
```

- s 是"该点到其投影背面的相对深度"，不是物理深度；同一个小物件各角用同一 s
- 经验值：窗台/搁板 s≈0.05~0.08；柜体 s≈0.15~0.2；桌面 s≈0.25~0.3
- 收束后同深度的点连线自动平行于画面（如前边水平，后边也水平且更短）

## 3. 侧墙物件（以右墙挂画为例）

侧墙平面内：竖线保持竖直；水平方向 = 过 VP 的直线。

做法：先定左边竖边的两个端点 (x1,y1t)、(x1,y1b)，则：
- 顶边斜率 m1 = (y1t − 330)/(x1 − 640)
- 底边斜率 m2 = (y1b − 330)/(x1 − 640)
- 右边竖边在 x2 处：y2t = 330 + m1×(x2−640)，y2b = 330 + m2×(x2−640)

实例：左边 x1=1000, y1t=265, y1b=380；右边 x2=1140
→ m1 = −65/360 = −0.181，y2t = 330 + (−0.181)(500) = 240
→ m2 = 50/360 = 0.139，y2b = 330 + 0.139×500 = 399.5

```svg
<polygon points="1000,265 1140,240 1140,399.5 1000,380"/>
```

内框不必严格推算，四个角各向内缩 10~16px 肉眼无感。

## 6. 墙上文字的倾角

侧墙上的文字应与该处纵深线平行。文字锚点 (x,y) 处的倾角：

```
angle = atan((y − 330) / (x − 640))   （度）
```

```svg
<text transform="rotate(11 1072 418)" x="1072" y="418">…</text>
```

后墙上的文字保持水平，零处理。

## 7. 参数速查

| 参数 | 含义 | 建议值 |
|---|---|---|
| VP | 灭点 | 画面中心附近，(0.5w, 0.45~0.5h) |
| d | 房间进深 | 0.45（扁宽）~ 0.6（深邃） |
| s（小物件） | 窗台/搁板深度 | 0.05~0.08 |
| s（柜体） | 落地柜深度 | 0.15~0.2 |
| s（桌面） | 桌子进深 | 0.25~0.3 |
| 外轮廓描边 | 房间棱、大门大窗 | 3.4~4px |
| 结构描边 | 家具外框 | 2.8~3.4px |
| 细节描边 | 纹理、刻度、装饰 | 1.4~2px |

## 8. 窗外景物剪裁

窗外内容（天空、海、灯塔、雨、光束）统一包一层 `<g clip-path="url(#winClip)">`，clipPath 取窗玻璃内框。物件宁可在窗内放小一点，也不要跨框被裁成半个——灯塔等标志性物件先算边界再落笔。
