# 样例 01：黑屏虚构声明（Fiction Warning）

## 用途

片头的免责声明页。3 秒、纯黑底、中英双语。作用是在正片开始前把观众"按"进虚构叙事，同时给后续的档案类 HUD 场景做调性铺垫。这一段刻意不做动效花活——只有排版、字距和克制的淡入淡出。

适用于：纪录片式虚构叙事、伪档案/伪监控题材、需要"免责声明 + 品牌片头"过渡的项目。

## 画面构成（1920×1080 基准坐标）

| 元素 | 内容 | 位置 | 规格 |
|---|---|---|---|
| 中文声明（两行） | 本片所包含的时间、地点、人物及其他内容均为虚构 / 与真实人物、机构或事件无关。如有雷同，纯属巧合。 | 居中，首行顶边 y=446，行高 1.95 | 19px，字距 2.6px，色 `#b9b9bc` |
| 英文声明（两行） | All times, places, persons and other content in this film are fictional and / have no connection to real persons, institutions or events. Any similarity is coincidental. | 居中，首行顶边 y=588，行高 1.8 | 12.5px 等宽，字距 0.4px，色 `#6c6c70` |
| 左下机读编号 | `RECORD A-0031 / 2029-0000 / FICTIONAL` | left 104, top 1042 | 11px 等宽，字距 2.2px，色 `#3c3c40` |
| 右下分辨率 | `1920 × 1080` | right 106, top 1042 | 同上 |
| 左上标记点 | 无文字，7×7 小方块 | left 116, top 64 | 色 `#6e1119`（暗红） |
| 暗角 | 径向暗角 | 全屏 | 边缘 55% 黑 |

配色只有五个值：

```
背景   #000000
中文   #b9b9bc
英文   #6c6c70
角标   #3c3c40     ← 刻意压暗，正常观看几乎看不见，截图放大才读得出
标记点 #6e1119     ← 暗红，读作"录制中"指示灯，不是强调色
```

## 时间轴

| 时间 | 事件 |
|---|---|
| 0.00–0.22s | 全黑 |
| 0.22–1.05s | 中英正文淡入（easeOutCubic） |
| 0.85–1.55s | 角标（编号 / 分辨率 / 标记点）淡入 |
| 2.50–2.96s | 全部淡出（easeIn），随后硬切下一场 |

淡入 0.83s 比淡出 0.46s 慢：观众要读完两行中文；淡出快，是为了把"结束"处理成信号切断而不是优雅退场。

## 实现要点

**正文与角标分开计时。** 两组元素的淡入区间不同，淡出统一用 `Math.min(fadeIn, 1 - fadeOut)`，保证段尾一定归零，不会残留半透明文字。

```ts
const fadeOut = ramp(lt, [dur - 0.5, dur - 0.04], [0, 1], EASE.in);
const body = Math.min(ramp(lt, [0.22, 1.05]), 1 - fadeOut);
const corner = Math.min(ramp(lt, [0.85, 1.55]), 1 - fadeOut);
```

**用绝对定位而不是居中容器。** 四组文字的位置是像素级对齐的（y=446 / 588 / 1042），`position: absolute` 直接落点比嵌套 flex 更容易和参考帧对齐，也方便单点微调。

**暗角不能省。** 纯黑底压过 h264 会出现轻微色块，叠一层 55% 径向暗角可以把边缘统一压死，中心仍为纯黑不影响文字对比。

**中文行高用倍数而非固定像素**（1.95 / 1.8），这样换字号时两行间距比例保持不变。

## 字体

| 用途 | 建议 | 说明 |
|---|---|---|
| 中文 | 任意黑体（PingFang SC / 微软雅黑 / Noto Sans CJK） | 这一段不依赖特殊字形 |
| 西文 / 数字 | 任意等宽（Consolas / Share Tech Mono） | 等宽让 `RECORD A-0031 / 2029-0000` 这类编号有档案感 |

若要接入本技能的字体子集化流程，把中文字体配进工程 `fonts.json`，由 `scripts/fonts.py` 生成 woff2 后用 `@remotion/fonts` 的 `loadFont` 注册。

## 复用方式

1. **换文案**：改 `ZH` / `EN` 两个数组即可，居中会自动跟随；中文超过 24 字建议降到 17px 或拆三行
2. **换时长**：工程版改 `timing.scenes.open`，自包含版改 `DURATION` 常量，淡入淡出的绝对时间会保留
3. **换调性**：想更冷就把中文色退到 `#9aa0a5`、标记点改青灰；想更"录像带"就加 `feTurbulence` 噪点和横向扫描线（本样例没加，因为参考调性这一段是干净的）
4. **接下一场**：结尾是硬切，接任何档案界面类场景都成立；如果下一场是亮底，建议最后 4 帧叠一层白场闪入，避免纯黑到亮白的突兀

## 已知取舍

- 英文为居中两行。若要更"数据流"的观感，可改左对齐并加 `whiteSpace: nowrap`
- 左上标记点位置固定（116, 64）。若下一场左上角有 HUD 标题（如 `ARCHIVE A®`），这个点会抢位置，届时应移到标题左侧或删掉
- 未加噪点/扫描线：这一段是"干净的档案页"而不是"劣化的录像带"，两种调性不要混用
