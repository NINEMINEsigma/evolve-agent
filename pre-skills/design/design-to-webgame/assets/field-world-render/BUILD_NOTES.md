# Field「场」— 程序化世界渲染（BUILD_NOTES）

本目录是「场」程序化落地页的完整源码（不含 vendor，需自行 vendored three webgpu + tsl）。
它演示了一整套**地图级 / 生态级程序化渲染**手法：滚动只产两个数，场景据此推导一切。

## 本资产适合的形态
- 开放地形 / 程序化生态 / 滚动式环境叙事
- 需要**零素材**（无贴图 / 模型 / 高度图）的沉浸式场景
- 形态随进度 / 状态连续变形的「一段世界」

## 目录结构
`src/site/scroll.js`（滚动→双数驱动）、`src/scene/{stage,field,tsl-common,terrain,sky,palette,uniforms}.js`、
`index.html`、`styles/main.css`。与 3d-object 的 `field-wgpu` 同源，此处侧重「搬进游戏世界」。

## 可迁移到游戏世界的契约

### 1. 状态驱动（最简契约）
页面只产 `travel`(0..1) + `phase`(0..n)。渲染器不知道页面，只读这两个数推导相机/光色/泛光。
这是「数据驱动世界」的极简形式——把世界的所有自由度压缩成两个标量，契约越小越好易换源。

### 2. 计算通道多态（零加载换形态）
每帧 `renderer.compute()` 重写存储缓冲，描述每个实例「此刻是什么」，顶点只弯带子。
四种状态（草 / 潮汐 / 余烬 / 晶格）共享同一批几何与材质，只是数字不同。

### 3. 高度场脊柱
`surfaceHeight` 同时驱动地形位移 + 生态定位，二者永不矛盾。改这一个函数即改整个世界
的地形语言。

### 4. 调色板即世界
每态一整组「天空 / 太阳 / 雾 / 地面 / 相机 / 泛光 / 曝光 / 颗粒 / 暗角」，CPU 按权重混合推
uniform。换世界观 = 改 `palette.js`，不动渲染管线。

### 5. 密度收敛（Vogel + 空场）
Vogel 螺旋盘 + 镜头加权 + `skip` 中心空场：远处不糊成噪点、近处不稀、不怼脸。

### 6. 自适应降档 + 降级
`TIERS` 自动减实例 / DPR；无 WebGPU 显说明页；reduced-motion 关动效。性能是体验的一部分。

## 玩法化改造思路
- 把 `phase` 映射到「世界阶段 / 关卡」，滚动即推进关卡
- 把 `surfaceHeight` 换成游戏地形，`field` 换成生态实例（建筑 / 植被 / 单位）
- 保留计算通道多态：同一批实例随阶段变形态（如白天→夜晚→地形塌陷）
- 若需交互 / 对抗，把驱动源从「滚动」换成「游戏逻辑」，契约不变
