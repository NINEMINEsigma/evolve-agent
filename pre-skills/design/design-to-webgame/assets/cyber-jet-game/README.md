# 赛博战机 — 霓虹峡谷之雨

一场在浏览器里实时运行的 3D 空战，舞台是暴雨中的赛博朋克巨型城市峡谷。完全
自包含、单机：打开页面就落到起跑线上，和三名 AI 王牌进行 3 分钟的命中数死斗。
没有服务端，没有构建步骤，没有网络 —— 只有普通静态文件和 ES 模块。

## 运行

任意静态文件服务器都行（ES 模块需要 `http://`，不能用 `file://`）：

```sh
python3 -m http.server 8000
# 然后打开 http://localhost:8000/
```

桌面版 Chrome/Edge/Safari，WebGL2，默认画质档（均衡）下 1080p 约 60 fps。
画质和声音设置在「设置」里，存在 `localStorage`。

## 操作

| 输入 | 动作 |
| --- | --- |
| 鼠标 | 转向 —— 偏离屏幕中心即压坡度 |
| 左键点击 / 按住，或 J | 发射等离子弹（连发） |
| E | 使用手中道具 |
| W / S | 加速 / 减速（27–54 米/秒巡航区间） |
| Shift | 推进加速到 74 米/秒 —— 会积热；满热后锁定约 2.2 秒 |
| 空格 | 垂直点火 —— 瞬间拉升（1.9 秒冷却） |
| Esc | 暂停 / 返回 |

菜单：`↑/↓` 或 `W/S` 选择，`Enter/空格` 确认，`←/→` 循环数值，`Esc` 返回；
鼠标悬停即选中，点击即确认。

## 空战规则

- **3 分钟一局，命中数最多者胜。** 没有血量：被弹丸或攻击型道具命中会让你的
  **系统离线 2 秒** —— 操作失灵、机身下坠翻滚 —— 恢复后有 1.2 秒的免疫期
  （顶部那条是眩晕恢复条，可控时为青色，离线时红色递减）。
- **只有格栅会杀死你：** 撞上高塔/平台/立柱/桥会直接爆炸（2.6 秒重生，
  2 秒出生无敌，击杀提示会记在「格栅」头上）。擦地只会溅火花。
- **弹丸：** 170 米/秒，0.22 秒间隔，2.4 秒生命，沿你的速度向量发射 ——
  你往哪飞就往哪打。命中**以受击方为准**：每颗弹丸都在受击方自己的代码路径上判定。
- **道具：** 霓虹箱子分 4 排 × 3 个位置漂在循环路线上（8 秒刷新，一次只能持有
  一个，按 `E` 使用）：
  - **冲击波** —— 以自身为中心 28 米范围的眩晕爆发
  - **电磁脉冲** —— 自动锁定对手中当前命中数领先者
  - **护盾** —— 8 秒，吃掉下一次命中（弹丸或道具）
  - **疾冲** —— 2.5 秒超越加速上限的免费冲刺，不积热
- **开局流程：** 所有人以编队停在同一条起跑线上等待；4 秒的「n 秒后出击」
  倒计时结束后开打。
- **竞技场：** 峡谷每 480 米重复一次（周期性区块种子）—— 无缝循环；
  高度上限固定为 84 米。

## AI 飞行员

三名对手（`js/arena/bots.js`）用计算出的输入跑同一套 `stepShip` 物理：油门/加速
管理、峡谷前瞻避障、提前量瞄准、按规定的 0.22 秒间隔点射。它们的坠毁、眩晕、
重生和计分走的是和玩家完全相同的代码路径，它们的弹丸也通过共享的 `Combat` 池
以受击方为准判定。你的冲击波/电磁脉冲会在本地交给它们判定。AI 不捡道具箱，
并且各自有一点技术差异，好让这局打得过。

## 架构

- `index.html` —— 入口：HUD + 菜单标记、自包含 CSS、import map。
- `js/arena/main.js` —— 空战编排：启动、对局流程（菜单/倒计时/进行中/暂停/结束）、
  输入、眩晕/死亡/重生、待机与追机镜头、HUD、`window.__arena` 调试钩子。
- `js/arena/menu.js` —— 右栏终端菜单：页面、选择、入场错峰、合成的导航/确认
  提示音、设置持久化。
- `js/arena/ship.js` —— 战机构建（着色的无人机机体 + 球形飞行员、名牌/信标精灵）
  + 共享飞行物理 `stepShip`。
- `js/arena/combat.js` —— 池化等离子弹、开火逻辑、以受击方为准的命中判定。
- `js/arena/items.js` —— 拾取箱、四种道具及其本地判定。
- `js/arena/bots.js` —— 三名 AI 飞行员。
- `js/config.js` —— 全部调参常量：世界区块、玩家物理、画质预设、
  `localStorage` 键。
- `js/engine.js` —— WebGL2 渲染器 + 自定义 HDR 后处理链（带 NaN 防护的亮部提取、
  亮度加权 mip 泛光、ACES + 青色调色、程序化镜头雨、色差、加速扭曲、暗角、颗粒、
  FXAA）+ 平面反射通道。
- `js/city.js` —— 程序化城市：canvas 霓虹招牌图集（中英文）、自定义着色器
  （窗格高塔、霓虹招牌、全息投影、湿滑反射街面、信标、光柱）、带种子的 160 米
  区块环（每 3 个区块重复一次以形成竞技场循环）、障碍查询、远景天际线。
- `js/life.js` —— 车流与氛围：148 辆实例化汽车、52 辆空中出租、蒙皮行人池、
  GPU 雨（≤7000 条相机环绕雨丝）、蒸汽广告牌、共享的叠加 GlowPool。
- `js/sky.js` —— 自下而上被照亮的暴风云天穹 + 供 PBR 模型使用的程序化 PMREM 环境。
- `js/assets.js` —— GLTF 加载与归一化、动画片段库。
- `js/utils.js` —— 带种子随机数、damp/lerp 辅助、共享的解析式高度雾 GLSL +
  `onBeforeCompile` 补丁器、全局逐帧 uniform。
- `vendor/three/` —— Three.js **r170** + 插件 GLTFLoader、BufferGeometryUtils、
  SkeletonUtils。ES 模块经 import map 引入，无构建步骤。
- `fonts/` —— Geist Mono 200/400/500（woff2）。

## 素材

每个模型都是原创，由基本体搭建并以小体积 GLB 放在 `assets/models/`
（不含任何第三方素材）：`drone-cab.glb`（战机）、`drone-patrol.glb`（环境巡逻机）、
`drone-interceptor.glb`、`android.glb` + `android-clips.glb`（行人）。
五个 GLB 合计约 1.4 MB。其余一切 —— 城市、高架、车流、雨、蒸汽、招牌、UI ——
都是程序化生成的。

## 调试钩子

`window.__arena` 暴露 `{ P, mode, combat, scoreboard, myShip, LOOP, dzLoop,
bots(), startMatch, quitToMenu, endNow(), step(nowMs) }` —— `step` 用于无头测试
时手动推进一帧，`endNow` 立即结束当前对局。
