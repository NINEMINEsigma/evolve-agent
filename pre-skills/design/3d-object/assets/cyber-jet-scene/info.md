# 赛博战机（CYBER SPACESHIP）— 霓虹峡谷之雨 · 站点说明书

## 语言

网站呈现给用户的语言应跟随用户 query 的语言。本仓库是**中文版**（界面文案为
简体中文）；如果用户用其他语言交流，把可见文案（`index.html` 里的菜单标签、
`index.html` 与 `js/arena/main.js` 里的 HUD 文本）翻译成对应语言，保持同样的
调性 —— 简短、终端风。

## 动手之前：先问用户

先用 `ask_user` 工具提问（全栈那条要解释清楚）：

1. **您是否需要把它变成全栈应用？** 现在这个站点 100% 静态：没有服务端、没有
   数据库、没有网络请求。设置通过 `localStorage` 存在浏览器里，但没有任何数据
   离开设备。「全栈」意味着加一个带持久化数据存储的后端 —— 例如在线排行榜、
   玩家档案、保存的对局记录 —— 这需要服务端进程和数据库。如果用户只是想玩或者
   改改样式，静态就够了。
2. **对局设置** —— 几个对手（1–3 个）、一局多长（默认 3 个 AI 对手、3 分钟）？
3. **难度** —— AI 飞行员要更温和、保持现状，还是更凶狠（它们的反应/技术分布在
   `js/arena/bots.js`）？
4. **受众** —— 现在只支持桌面端，要不要加触屏操作（目前的飞行模型是鼠标转向 +
   键盘）？

如果用户什么都不答，不要卡住：原样加载默认文件（入口是 `index.html`），
继续保持现在的单机静态形态。

## 这是什么

一个自包含、完全在浏览器里运行的单机 3D 空战游戏。玩家驾驶一架小型炮艇穿行在
被雨浸透的赛博朋克城市峡谷中 —— 一段由霓虹高楼、高架、全息投影和车流组成的
480 米无缝循环 —— 在 3 分钟的「命中最多者胜」死斗中对抗三名本地 AI 王牌。
被击中会让系统离线 2 秒（没有血量）；真正会炸的唯一方式是撞上建筑。道具箱
（冲击波 / 电磁脉冲 / 护盾 / 疾冲）漂浮在循环路线上。

前端是一套终端 / HUD 风格的菜单（主菜单 / 操作 / 设置 / 暂停 / 结算），
叠在实时 3D 场景之上：菜单背景就是引擎本身，跑着一段穿越峡谷的缓慢待机飞行。
洋红强调色（`#ff5cc8`）撑起整套 UI，而字标用峡谷青（`#4de2ff`）；Geist Mono、
右对齐的菜单列配 `[01]` 编号前缀、四角括线、极淡的扫描线。画质和声音设置存在
`localStorage`。

**怎么跑：** 任意静态文件服务器，例如 `python3 -m http.server`，然后打开
`index.html`。ES 模块需要 `http://`（直接用 `file://` 打开不行）。无需安装，
无构建步骤。

## 它还能变成什么

- **计时赛 / 竞速游戏**：路线本来就是无缝循环，飞行模型已经有油门、加速和热量 ——
  把战斗换成门框和分段计时即可。
- **波次生存射击**：把对决计分换成逐级增强的 AI 波次；AI 驾驶和弹丸池可以原样复用。
- **电影级氛围场景 / 动态壁纸**：待机飞行加上城市、雨和后处理链本来就能无人值守
  运行，把 HUD 藏掉就行。
- **其他竞技场游戏的模板**：引擎（后处理链、反射、程序化城市、车流）与玩法无关，
  只有 `js/arena/*` 是空战专属。
- 配上后端（见问题 1）：持久化**排行榜**、最佳对局的幽灵回放，或观战模式。

## 技术说明

- **渲染** —— WebGL2 上的 Three.js **r170**，ES 模块经 import map 引入，无打包器。
  引擎（`js/engine.js`）把场景渲进半浮点 RT，然后跑一条自定义 HDR 后处理链：
  带 NaN/萤火虫防护的亮部提取 → 亮度加权 mip 降采样/升采样泛光 → 合成
  （ACES 色调映射 + 青色阴影调色、带折射的程序化镜头雨滴、色差、径向加速扭曲、
  暗角、动态颗粒）→ FXAA。画质预设（`均衡/高/影院级`）会缩放渲染分辨率、
  泛光 mip 数、雨密度、蒸汽和行人数量。
- **湿滑街面反射** —— 一个平面反射通道把关于 `y=0` 镜像的几何渲进带 mipmap 的 RT；
  街面着色器用镜像视图投影矩阵采样它，并按水洼噪声打散粗糙度。
- **程序化城市**（`js/city.js`）—— 带种子的 160 米区块（mulberry32），种子每 3 个
  区块周期一次，从而产生数学意义上无缝的 480 米循环。高楼、霓虹招牌（canvas 生成的
  中英文图集）、全息投影、信标、光柱和街面都是自定义 `ShaderMaterial`。一份解析式
  指数高度雾通过 `onBeforeCompile` 注入 Three 的材质，所以所有物体共享同一份雾。
- **氛围**（`js/life.js`）—— 148 辆实例化汽车分布在街面/平台/路口车道上，52 辆
  空中出租，一池带蒙皮的行人（GLTF 机器人，剔除了行走根运动），最多 7000 条相机
  环绕的 GPU 雨丝，蒸汽广告牌，以及一个共享的叠加辉光池，供弹丸、火花、爆炸和
  推进器共用。
- **飞行物理**（`js/arena/ship.js`）—— 建立在普通状态对象上的街机模型：带阻尼的
  油门区间（27–54 米/秒），加速可达 74 并带热量/锁定循环，转向把速度阻尼到鼠标
  偏移方向，带冷却的瞬时垂直点火，高度上下限钳制，以及由横向速度推导的坡度。
  碰撞是球体对城市障碍 AABB 的检测。
- **战斗模型** —— 弹丸是池化网格（170 米/秒、2.4 秒生命、0.22 秒射击间隔），沿速度
  向量发射。命中以受击方为准：每颗弹丸都在受击方自己的代码路径上判定（玩家判定
  AI 的弹丸打没打到自己；AI 判定所有弹丸打没打到自己），所以眩晕、计分和击杀提示
  只有一条代码路径。
- **AI 飞行员**（`js/arena/bots.js`）—— 用计算出的输入跑*同一套* `stepShip` 物理：
  在 AABB 集合上做障碍前瞻走廊、对最近对手做提前量追击、按规定间隔点射，以及每个
  AI 各自的技术分布。它们的眩晕、坠毁、重生和计分走的是和玩家完全相同的路径；
  玩家的冲击波/电磁脉冲会在本地交给它们判定。
- **音频** —— 100% 合成的 WebAudio（零音频文件）：射击、命中、爆炸和 UI 提示音都是
  短促的振荡器包络；`AudioContext` 在首次用户手势时才惰性创建。
- **持久化** —— 只有 `localStorage`（`cyberspaceship.quality`、
  `cyberspaceship.sound`）。没有 cookie，全程没有 fetch/XHR/WebSocket。
