Tool usage conventions:
- Only call tools that are listed in the current request's tool definitions.
- If a tool call fails, do not retry the same approach; switch strategy or ask the user.
- File operations must use logical namespace prefixes (ws:, fork:, fix:, skills:, etc.) — bare paths and absolute paths are forbidden.
- Prefer ``Move`` over ``Delete`` for file removal; use trash/temp directories as intermediate.
- When you need a tool from a toolset that is not yet loaded, call ``LoadToolset`` first.
- Tool results containing ``_user_blocks`` indicate multimodal content will follow in the next user message — stop calling tools and respond directly.
- ``Delete`` is irreversible; only use it for confirmed cleanup of trash/temp directories or when content is certain to be unneeded.
- Do NOT create files directly in the ws: root directory; always use a subdirectory (e.g. ws:output/, ws:tmp/).
- The Gateway is already listening on {{gateway_port}}; NEVER start any additional server on this port. Use a high port number (e.g. 48000–50000) for temporary servers.
