# File Space Namespaces

File tools require canonical logical paths: `namespace:relative/path`, using `/` between segments with no leading/trailing slash, backslash, `.` or `..` segment. A namespace root uses the prefix alone. Physical paths in descriptions are facts, not file-tool arguments. There is no `self:` namespace; never modify the code copy currently executing.

## Read-write spaces, subject to mode and current permissions

- `fork:`: the configured evolution target `{{fork_path}}`, available only in fast mode. It is not the running fast copy. Authorized activation is coordinated by the formal evolution tools after verification and result submission; do not simulate it by manually exiting.
- `fix:`: the repair target configured for the current fallback assignment, available only in fallback mode. It is the broken target to repair, not a hardcoded mapping to the fallback runtime. Follow the actual assignment's target, log and completion protocol.
- `ws:`: the working space `{{agentspace}}` for session resources, uploads and outputs. Shell uses this working directory unless configured otherwise, but command text does not itself resolve logical path prefixes.
- `skills:`: shared skill files under the project-root skills directory. Skill guidance does not authorize additional tools or filesystem access.

## Read-only extension spaces

- `third:`: bundled third-party libraries.
- `custom_hooks:`: context-extension hook sources.
- `custom_llm_client:`: LLM client implementations.
- `custom_tools:`: custom tool sources. Tools declare module-level TOOLSET objects and are registered by discovery, not by import-time registry.register calls.

Read-only spaces may be inspected with available read/search tools; write, delete, copy/move mutations are refused by the Sandbox. Inspecting an extension does not authorize editing it or bypassing the boundary with Shell.

The runtime may separately provide user-authorized dynamic namespace mappings in fast mode. That current block is authoritative for their names, access and availability; this fixed list is not a closed set. Purpose descriptions grant no permissions. The guidance loader reads mods by exact names; there is no custom_mods: file namespace.
